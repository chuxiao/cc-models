## 2. 场景清单

### V-01 标题语义变更【自动化（单元测试，Task 1 内）】
- 期望：statusItemTitle 短名/13 字符截断断言按新语义通过；titleWriter 时序断言 `["—"]`/`["—", "智谱"]` 通过；其余断言（受 I-1 影响 3 个测试函数 6 处断言之外的全部）零改动通过。出处：implementation §I-1。
- 判据：swift test 全绿（139+ 条）。

### V-02 状态项图标形态【人工】
- 前置：应用运行。
- 步骤：观察浅色与深色菜单栏下的状态项（可在系统设置切换外观）。
- 期望：双向箭头图形图标 + 模型名并列；明暗菜单栏均清晰；无「⇄」文本前缀。出处：design §V1、mockups/exploration.html icon-swap 卡。
- 清理：无。

### V-03 三窗口深色主题【人工】
- 步骤：依次打开偏好设置、首跑窗（需 CC_MODEL_CONFIG_DIR 临时目录）、导入弹窗（settings.json 改为未匹配值后开关菜单一次）。
- 期望：三处均为深色主题，色感与冻结稿一致（深卡面、渐变主按钮、弱化辅助文字）；浅色系统下窗口仍深色。
- 深色可用性核对（design §V2 承接）：在偏好窗清空显示名点保存触发行内校验提示 → 红色提示与 Token 行密文点在深色下清晰可辨。
- 清理：恢复备份；移除临时目录。

### V-04 窗口居中【人工】
- 步骤：依次打开四个窗口/弹窗，观察出现位置。
- 期望：每次打开均居中于屏幕（主屏），不再出现左上级联位置。出处：design §V3。
- 清理：无。

### V-05 偏好窗口尺寸与密度【人工】
- 步骤：打开偏好窗口，观察尺寸与字段间距；尝试拖拽缩至最小。
- 期望：默认 720×480（可用窗口信息或截图比对）；最小约 660×430；字段不再拥挤，四档映射横排四列。出处：design §V4、mockups/preferences.html。
- 清理：无。

### V-06 首跑窗隐藏默认行【人工】
- 前置：CC_MODEL_CONFIG_DIR 指向空临时目录；真实 settings.json 备份就绪。
- 步骤：启动应用 → 首跑表单观察 → 保存。
- 期望：表单无「设为默认」行；保存后模型仍自动成为默认（菜单带「（默认）」标注）。出处：design §V5、implementation §I-4。
- 清理：恢复备份；删临时目录。

### V-07 弹窗三出口行为回归【人工】
- 前置：V-03 的备份前置就绪。
- 步骤：深色化后依次执行三出口——纳入（含重名输入）、覆盖、取消（含重启核查不再弹）。
- 期望：三出口行为与既有语义完全一致——重名保持弹窗、覆盖三项保持（env 整体替换、显示名/默认不变、成为当前）、取消记 dismissed。出处：design §3 第 1 条（行为零变更）。
- 清理：恢复备份。

### V-08 全量回归【自动化】
- 期望：swift test 全量通过（既有 139 条，I-1 断言已按新语义更新）。出处：plan §4 约束。

## 3. 通过判据

- 自动化：`swift test` 全绿（含 statusItemTitle 新语义断言与既有回归）。
- 人工：V-02 ~ V-07 每条期望逐项核对通过；任一不符即失败，证据（截图）采集后集中呈报需求方定性。

## 4. 验证环境

- `swift test`（仓库根）；人工场景：开发目录 `swift run` 或 `make-app.sh` 产物；归档方案 S6 类场景（首跑隔离）用 `CC_MODEL_CONFIG_DIR`。

## 5. 执行手段

- 自动化：V-01、V-08 进 swift test 套件。
- 人工清单：V-02 ~ V-07（已在场景标题标注【人工】）；机器步骤（备份/恢复/改 env/启动）由控制者执行，观察点由需求方确认。

## 6. 内容要求落实

- 确定性固定策略：V-01/V-08 以测试断言承载；人工场景期望引用冻结稿与逐字口径。
- 保真度声明：视觉观感的最终裁定权在需求方（冻结稿为其确认物）。
- 副作用隔离：触真实 settings.json 的场景（V-03、V-06）先备份后恢复；V-06 用临时配置目录。
- 顺序依赖：V-06 依赖临时目录前置；V-07 依赖 V-03 的备份前置。
- 既有登记册查重：除 V-07 为既有弹窗语义回归（对应登记册 S3/S4/S5）外，其余场景均为视觉新增，与既有登记册 15 条不重叠。
- 失败证据采集：截图 + swift test 输出。
